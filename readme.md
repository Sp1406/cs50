# CS50x - Introduction to Computer Science

This repository contains my problem sets, lecture code, and practice exercises for Harvard University's **CS50x: Introduction to Computer Science**.

---

## Progress Tracker

### Week 0: Scratch
- Topic: Fundamentals of computational thinking, algorithms, and visual programming.
- Projects:
    - `Pearl Diver.sb3` - Interactive Scratch project focusing on loops, conditionals, and events.

### Week 1: C
- Topic: Low-level programming concepts, data types, loops, conditionals, and memory fundamentals.
- Lecture Code:
    - `agree.c` - Handling user input and conditional checks
    - `cat.c` - Demonstrating while/for loops to repeat actions
    - `compare.c` - Comparing values
    - `hello.c` / `hello_you.c` - Basic printing and string input/output
    - `mario.c` - Printing blocks/pyramids using nested loops
- Section Practice:
    - `contacts.c` - Additional basic printing and string input/output exercise
    - `mario2.c` - Additional pyramid building exercise

## How to Run the Code

### Scratch Projects (`.sb3`)
1. Open [Scratch](https://scratch.mit.edu/).
2. Click **File > Load from your computer** and select `Pearl Diver.sb3`.

### C Programs (`.c`)
To compile and run any C program using the CS50 library, execute the following in your terminal:
```bash
make filename
./filename
```

Example:
```bash
make mario
./mario
```
